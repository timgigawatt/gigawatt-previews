### Block library — `src/blocks/`

### Announcement v1

Site-wide notice rendered by the layout from globals/announcements.json, not placed on a page. Shown while starts <= today <= ends. Only one may be active at a time.

- title: string ≤80
- body: string ≤400
- cta?: object
- starts: string
- ends: string
- placement?: home-only|all-pages (default "home-only")
- style?: popup|banner (default "banner")

### CardGrid v1

A grid of cards: services, team members, features. Each card has a title, text, optional image and link.

- variant?: services|team|features (default "services")
- heading?: string ≤90
- intro?: string ≤300
- columns?: 2|3|4 (default 3)
- cards: array<object>

### ContactForm v1

The Contact page: intro, a short form (never a form they don't have as their real flow — the CTA strategy in the brief decides; the preview form is not wired), and an aside with the phone, address, email, hours (globals/settings.json) and a service-area map placeholder.

- eyebrow?: string ≤30 (default "Contact")
- heading: string ≤60
- intro?: string ≤220
- fields?: array<object>
- messageLabel?: string ≤40 (default "How can we help?")
- messagePlaceholder?: string ≤80
- submit?: string ≤30 (default "Send")
- note?: string ≤160
- showForm?: boolean (default true)

### CtaBand v1

The closing band on the home page, in the primary colour: a headline, one line, the phone number as a big button and the site CTA beside it (both from globals — settings.phone, nav.cta). Converts the scrollers who ignored the header.

- heading: string ≤60
- text?: string ≤160

### Gallery v1

Proof of work in their own photos. `grid` = square tiles (2–6, captions optional); `before-after` = two 4:3 frames labelled Before / After (Foundry). Slots with no usable photo render as tinted placeholders; a Gallery with no photos at all still reads as finished, so include it only when the profile has at least one usable photo or the composition asks for it.

- variant?: grid|before-after
- heading: string ≤60
- images?: array<image>
- placeholders?: integer

### Hero v2

Top-of-page banner: eyebrow (service area), headline in their words, supporting line, up to three proof bullets, two CTAs, and a photo grid on the right — one 4:3 photo, one 1:1 photo, one badge tile. Personality flags: `band` draws the tinted dotted band behind it, `diagonal` cuts into the next section. Always the first block on the home page.

- eyebrow?: string ≤60
- heading: string ≤90
- subheading?: string ≤220
- bullets?: array<string>
- primaryCta?: cta
- secondaryCta?: cta
- image?: image
- image2?: image
- badge?: object

### Marquee v1

Full-width scrolling strip of program names or results (Kinetic's move — only in a personality with the `marquee` flag). Decorative: the same words must appear elsewhere on the page.

- items: array<string>
- tone?: primary|surface (default "primary")

### PageHeader v1

The first block of an inner page (Services, About): eyebrow, h1, one line, on the recessed surface. Never on the home page — that is the Hero.

- eyebrow?: string ≤30
- heading: string ≤80
- intro?: string ≤220

### Pricing v1

Two to three tiers, only when they publish prices or plans: name, price, per, note, bullet list, the site CTA. Never invent a price.

- heading: string ≤60
- tiers: array<object>

### ProofRow v1

A single row of trust chips right after the hero: licences, affiliations, hours, "open today", ratings — only what the profile's Proof section has. Four to six items.

- items: array<string>

### PullQuote v1

Exactly one editorial pull-quote per page (Ledger's move — only in a personality with the `pull` flag): a hanging serif quote at h1 scale, a gold hairline above, nothing else in the band. The quote is the owner's or the business's own words from the profile, never a review.

- text: string ≤160
- who: string ≤40
- role?: string ≤40
- tone?: surface|bg (default "surface")

### Services v1

What they do, in their words, with a price signal on every row only when they publish one. `list` = ruled rows (title · description · price); `bento` = one anchor tile plus mixed-span tiles, first four items (Clarity's move); `cards` = uniform cards with a Book link (the Services page). Variant defaults from the personality.

- variant?: list|bento|cards
- heading: string ≤60
- more?: cta
- ctaLabel?: string ≤20 (default "Book →")
- items: array<object>

### Stats v1

Two to four numbers the business already publishes: years, jobs, rating + count, loaves a day. `numerals` = oversized display numerals under a thick rule (Foundry's move); `row` = a quieter three-up. Variant defaults from the personality.

- variant?: numerals|row
- heading?: string ≤60
- items: array<object>

### Team v1

Named people with roles, 3:4 portrait slots — only people the profile names; a slot without a usable photo is a tinted placeholder.

- heading: string ≤60
- people: array<object>

### Testimonials v1

Three to five review quotes as a scroll-snap carousel of cards (five accent dots, the quote, who + where). Quotes verbatim from public reviews, attributed exactly as shown publicly.

- heading: string ≤60
- items: array<object>

### TextSection v1

A heading and one or more paragraphs of markdown-lite text (paragraphs, **bold**, links). The general-purpose content block.

- variant?: narrow|wide (default "narrow")
- heading?: string ≤90
- body: array<string>
